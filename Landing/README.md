# Landing Page | YS.Creates

A premium, modern, elegant, and fully responsive creative web development landing page and portfolio built using only raw **HTML5** and **CSS3**.

## Brand Name
**YS.Creates**

## Project Description
YS.Creates is a personal creative web development portfolio landing page designed with rich visual aesthetics, glassmorphism elements, soft shadow hierarchies, and smooth micro-interactions. The layout is engineered to be mobile-first and fully adaptive to all standard viewport sizes (desktop, tablet, mobile) with clean, semantic markup and compliant accessibility practices.

---

## Features
- **Sticky Glassmorphic Navigation Bar**: Fully responsive layout with custom active states and smooth scroll links. Utilizes a pure CSS checkbox hack for mobile toggle controls (no JS required).
- **Hero Section**: Modern, high-impact heading and actions paired with a custom responsive SVG illustration.
- **About Section**: Multi-column split card highlighting core statistics, design ethos, and details.
- **Services Section**: 4 modern grid cards with styled icons and hover lift effects showing service offerings.
- **Why Choose YS.Creates**: 4 highlight cards showing core attributes (Clean Code, Responsive Design, Modern UI, Fast Performance) with hover states.
- **Portfolio Grid**: 6 interactive project cards showing custom SVG mockups with smooth image hover-zoom animations.
- **Testimonials Section**: 3 customer testimonial cards containing star ratings, text blocks, and modern avatar indicators.
- **Call-to-Action (CTA)**: High-contrast gradient layout encouraging prospective users to initiate contact.
- **Contact Form & Info**: Accessible form layout (for UI purposes) accompanied by exact brand communication channels.
- **Footer Section**: Comprehensive footer featuring logo indicators, copyright information, fast links, and social links placeholder buttons.

## Instructions to Run the Project Locally
To view the landing page:
1. Download or clone this repository.
2. Navigate to the `Landing/` folder.
3. Open `index.html` in any web browser of your choice (Google Chrome, Firefox, Safari, Microsoft Edge, Brave, etc.) by double-clicking it or dragging the file into a browser tab.
4. The page is fully offline-capable, requiring no active server environments or external dependencies to run.
